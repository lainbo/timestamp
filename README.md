# 时间戳转换

基于 Vue 3、Vite 8、UnoCSS 和 Arco Design Vue 的时间戳/日期转换工具。

## 开发

要求 Node.js `^20.19.0 || >=22.12.0`，并使用 pnpm。

```bash
pnpm install
pnpm dev
```

## 工具链

```bash
pnpm lint          # Oxlint
pnpm lint:fix
pnpm format        # Oxfmt
pnpm format:check
pnpm build         # Vite 8 + Rolldown/Oxc
pnpm check         # lint + format check + build
pnpm deps:check    # 检查依赖更新
```
