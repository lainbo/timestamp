# 时间戳转换

基于 Vue 3、Vite 8、UnoCSS 和 Arco Design Vue 的时间戳/日期转换工具。

## 时间转换

日期文字按所选时区的当地时间解析，支持 `YYYY-MM-DD HH:mm:ss` 和斜杠分隔的日期，月、日、时、分、秒允许一位数字。转换层会拒绝非法日期及夏令时切换时不存在的当地时间；时钟回拨产生的重复时间会给出两次出现的单选（标注发生顺序和 UTC 偏移），手动输入默认取第一次，点击“此刻”自动选中当前时间对应的那一次。时区列表展示当前偏移，转换标题展示对应日期的实际偏移。

日期文字可以带 1–9 位小数秒，例如 `2026-11-20 23:59:59.999`，`.9` 表示 900 毫秒；换算成时间戳时，超出所选单位精度的部分向下取整。时间戳转出的日期只在小数秒不为 0 时显示，按三位一组去掉末尾的 0，依精度显示 3、6 或 9 位。日期面板和“此刻”按钮精确到秒，在面板中点选并确定后会去掉手输的小数秒。

历史时区偏移中的秒数会参与转换计算。时间戳转换出的公元前日期带有“公元前”标识；日期输入使用四位年份，支持公元 0001–9999 年。

日期输入框始终显示手输的原文，包括格式、小数秒和尚未写完的文字；原文是有效日期时，面板同步选中对应的日期和时间。面板只处理墙钟上的年月日时分秒，以 UTC 模式的 Day.js 保存，点选不受系统时区的夏令时影响，支持 0001–9999 年。时间列默认 00:00:00，空面板中只选时间时，日期取系统时区的今天。面板点选的结果按“确定”或回车后写回输入框，格式为 `YYYY-MM-DD HH:mm:ss`；转换结果仍按所选时区计算。

## 开发

要求 Node.js `^20.19.0 || >=22.12.0`，并使用 pnpm。

```bash
pnpm install
pnpm dev
```

## 工具链

```bash
pnpm lint          # Oxlint
pnpm lint:fix
pnpm format        # Oxfmt
pnpm format:check
pnpm build         # Vite 8 + Rolldown/Oxc
pnpm run up        # 交互式检查依赖更新（npm-check-updates）
```

## 日期时间选择器

日期输入框和面板由 `src/components/DateTimePicker.vue` 实现，只使用 Arco 的 Trigger、Button、图标和 CSS 变量，日期与时间的计算都在组件内完成。外观参照 Arco Design Vue 2.59.0 `a-date-picker show-time` 的实际渲染，深色主题随 `arco-theme` 下的 CSS 变量切换，所在表单项校验失败时显示错误样式。组件用 `v-model` 双向绑定输入框原文，用 `v-model:popup-visible` 控制弹层，`extra` 插槽显示在面板底部左侧。

升级 Arco 或修改该组件后，对照浅色、深色主题检查输入框和弹层的外观，并在系统时区为纽约、豪勋爵岛时验证夏令时空缺点选（空面板中先选日期和先选时间两种顺序），以及重复时间选择、手输、清空和面板确认。
